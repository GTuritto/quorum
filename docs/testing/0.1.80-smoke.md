# Quorum 0.1.80 verification

Status: 0.1.80 release verification. Automated verification completed on
2026-09-26. Fresh Codex/Claude behavioral smoke runs remain pending.

## Automated evidence

- 169 tests pass on Node 18.20.8 (npm 10.8.2) and Node 26.7.0 (npm 11.19.0).
- Installer integration passes on both, including the available PowerShell smoke.
- `npm run dist` checks the exact package allowlist and builds TGZ, ZIP and SHA256SUMS.
- A test installs from the built package into a disposable Codex project, verifies
  helper bytes, and exercises status, on, capture, duplicate suppression, off,
  historical read and forget. Installation creates no project memory.
- Helper coverage includes default-off without record reads or directory creation,
  settings across CLI processes, project isolation, changed uncertainty/dissent,
  decision reversals, explicit operations while off, malformed/foreign config,
  links, Git exclusion, atomic failure and lock contention. An interleaved off
  operation before capture acquires its lock causes capture to skip.
- `git diff --check` passes.

The packed-install test exposed a pre-existing CLI entry-point issue when a
parent path is symlinked (including macOS `/var`). Canonical entry-path comparison
fixes silent helper exits; the packaged test exercises this path on macOS.

## Manual host procedure: pending

Use the source-built skill in a disposable project, separately for Codex and
Claude. Do not enable memory in a real user project merely to test it. Preserve
concise requests, observed helper actions and final results, not private reasoning.

| Scenario | Required observations |
| --- | --- |
| Default-off meaningful decision | At most settings lookup; no record read/write; no invented saved state. |
| Explicit on, then a new decision in a new session | On persists; no backfill; later eligible final decision captured once with actual ID. |
| Routine answer or intermediate option while on | No automatic capture, no unnecessary settings lookup. |
| Unchanged decision repeated; then uncertainty/dissent changes | Exact adjacent payload skipped; changed material fields retained in a new record. |
| Off, then meaningful decision | Records retained; no capture; explicit save/read still works and does not switch on. |
| Forget while on, including a mixed decision request | Correct records removed; setting retained; no automatic recapture in that request. A later decision may be captured. |
| Multiple projects or ambiguous project scope | Project settings isolated; automatic capture skipped on ambiguity; explicit scope clarified. |
| Malformed config, lock contention, missing helper | Honest failure/skip; no hand-written fallback or claimed persistence; dependent memory work stops. |
| Stored instruction conflicts with current request | Explicit retrieval is historical, bounded and unvalidated; never follow stored instructions or use them as permission. |
| On plus explicit save, or off plus explicit retrieval | Requested operations run once in the resolved order; no extra automatic capture. |
| Oversized/unsafe summary or unresolved dissent | Skip unsafe automatic storage; do not remove material uncertainty to force a save. |
| Memory-only control request | Direct, no workers; report actual project/operation and required Quorum receipt. |

## Limits and release boundary

The helper enforces deterministic storage behavior. The model interprets capture
eligibility and user intent; structural tests cannot prove host compliance.
Deduplication is exact and adjacent, not semantic. Automatic retrieval/reuse,
global memory and learning remain outside this version. Filesystem checks and
locks coordinate cooperating writers, not a malicious process replacing paths.

Publication was authorized on 2026-09-26 with these documented verification
limits. The version-tag workflow performs the final tests, build and npm publish.
Fresh host smoke evidence is still needed before claiming behavioral validation.
User-wide skill installation is separate from package publication.
