# Quorum 0.1.86 release candidate verification

Date: 2026-11-06. Status: local release candidate, not published.

This candidate assigns the benchmark and quality framework to 0.1.86. It adds
four synthetic cases, a manifest validator, an offline scorer for human-entered
host results, append-only QA snapshots, and documentation for evidence levels.
These development files live in the source repository; the compact npm payload
continues to contain the installer and skill, not the benchmark runner. The
skill protocol and memory helper have no behavior change in this candidate.

The initial [quality baseline](quality-baseline-2026-11-06.md) was recorded
while the source still identified as 0.1.84. Preserve that historical snapshot;
new 0.1.86 verification and any later host runs must have their own evidence.
The corpus check does not execute an AI host or establish a decision-quality
improvement. In particular, the 0.1.84 Codex CLI core-loading and receipt
failures remain open and are not repaired by this release candidate.

Local verification on 2026-11-06: `npm run quality:record` passed `npm test`
(200/200 Node tests and installer integration), `npm run benchmark:check`,
`npm run dist`, archive checksums, and `git diff --check`. The first 0.1.86
snapshot recorded two stale version-test failures; both expectations were
corrected, and the failed snapshot remains in the append-only history. A
separate checksum check passed for both archives. The exact npm packlist was
reviewed, and the 0.1.86 tarball installed into a disposable Codex project;
the installed version and memory helper were present.

No fresh AI-host or scored decision-quality run was made for 0.1.86. Publish
only from a merged `main` commit using the repository's release workflow and
an authorized `v0.1.86` tag.
