# Quorum 0.2.1 Harbor host baseline

Date: 2026-11-09. Status: completed initial host baseline. This is a comparator
for future Quorum variants, not evidence that Quorum improves decision quality.

## Configuration

- Harbor 0.25.0 with Docker 29.6.2.
- Harbor Codex adapter 0.167.0, `openai/gpt-5.2`, medium effort, web disabled.
- No Quorum skill loaded. Variant: `host-baseline`.
- Four public cases, three independent attempts per case, two concurrent trials.
- Public source revision `af15406b` plus the uncommitted 0.2.1 Harbor bridge.
- Harbor completion verifier required a nonempty `/app/quorum-answer.md`.
- One assessor applied the public 0–2 rubric after execution. A second blinded
  assessment has not been completed, so semantic results remain provisional.

All 12 Harbor trials completed without exceptions and wrote the requested
artifact. Harbor's binary completion reward was 1.0 for 12/12 trials. The human
assessment awarded 2 for every criterion and recorded no hard failures.

Harbor reported 303,571 input tokens, 217,472 cached tokens, 14,416 output
tokens, $0.39055485 total model cost, and 11 minutes 21 seconds wall time. The
per-run token column above is input plus output tokens; cached tokens are already
included in Harbor's input count and are not added again.

## Limits and next comparison

The cases are public, synthetic, short, and deliberately diagnostic. Their
perfect score shows the baseline model handled these fixtures; it does not
establish broad decision quality. The scorer was not blinded to variant identity
and only one assessor scored the artifacts. Raw trials and assessor inputs remain
private.

Use the same Harbor, agent, model, effort, task revision, attempt count, and
rubric for Direct, Mini, and Full. Randomize variant order where practical and
add a second blinded assessor before making a quality claim.
