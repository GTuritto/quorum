## Delivered candidate scope

A development-only Harbor 1.4 task exporter and human-assessment converter.
The existing scorer and append-only recorder own scoring, telemetry checks and
baseline comparisons. Harbor is optional and excluded from both npm and skill
payloads. No memory protocol, automatic reuse or host adapter behavior changes
are included in this candidate.

The exporter retains the synthetic task prompt and asks for a final artifact.
Rubrics are stored separately for assessors. The verifier checks artifact
presence only; its reward cannot establish decision quality.
