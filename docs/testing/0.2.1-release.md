# Quorum 0.2.1 release verification

Date: 2026-11-20, Europe/Madrid. Status: published and verified on npm.
[PR #6](https://github.com/GTuritto/quorum/pull/6) merged at
`c89fb4fc435ba3f1131bc4b9fdb5e7aae37ce693`; the annotated `v0.2.1` tag
triggered the successful [publishing workflow](https://github.com/GTuritto/quorum/actions/runs/44814554483).
No user-wide installation was updated.

## Delivered candidate scope

A development-only Harbor 1.4 task exporter and human-assessment converter.
The existing scorer and append-only recorder own scoring, telemetry checks and
baseline comparisons. Harbor is optional and excluded from both npm and skill
payloads. No memory protocol, automatic reuse or host adapter behavior changes
are included in this candidate.

The exporter retains the synthetic task prompt and asks for a final artifact.
Rubrics are stored separately for assessors. The verifier checks artifact
presence only; its reward cannot establish decision quality.

## Candidate verification

`npm run quality:record` passed 222/222 Node tests, installer integration,
benchmark corpus validation, exact packlist/distribution build, archive checksums
and the diff check. The [append-only QA snapshot](../../benchmarks/results/2026-11-20T20-26-26-414Z-af15406b-5ede862d.json)
records the dirty source state at `af15406b` and compares QA against the previous
snapshot. Decision-quality benchmarking is explicitly not run in this snapshot.
The code checks preceded this verification document and private roadmap update;
subsequent documentation received separate diff and link checks.

Eight added regression tests exercise missing provenance, malformed assessment
envelopes, unknown cases, invalid/extra scores and hard-failure flags, plus the
converter-to-scorer path. A converted perfect score with a hard failure keeps
the failure; missing telemetry remains unknown rather than zero.

A disposable offline CLI smoke also checked two byte-identical exports of all
four cases, parsed every task TOML with Python's standard library, checked each
verifier's shell syntax, checked all task instructions for rubric isolation,
and converted complete synthetic assessments through the report CLI. These
fixture assessments were not recorded as model performance or quality results.

from 2026-11-09 with one unblinded assessor. It was not rerun on 2026-11-20.
The Harbor executable was unavailable in the current shell. Direct, Mini, Full,
a second blinded assessment and held-out cases remain open. No comparative
quality improvement is established. Per the experiment plan, those comparisons
are separate from acceptance of the bridge itself.

The user authorized release on 2026-11-20. A fresh four-worker independent
review supports the development-only bridge scope with the limits above.
The [final preparation snapshot](../../benchmarks/results/2026-11-20T20-42-31-995Z-c6426dfd-63faaae8.json)
repeated all 222 tests, integration, corpus, distribution, checksum and diff
gates after synchronizing with `origin/main` and aligning the guide examples.
No comparative benchmark was run.
