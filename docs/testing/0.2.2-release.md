# Quorum 0.2.2 release verification

Status: published and registry verified on 2026-11-20.
[PR #8](https://github.com/GTuritto/quorum/pull/8) merged at
`6fd7d06751ac92db0290591f36adf421cb3f49a7`. The annotated `v0.2.2` tag
triggered the successful [publishing workflow](https://github.com/GTuritto/quorum/actions/runs/44831260357).
No user-wide installation was changed.

## Activation and compatibility

Project memory on enables bounded automatic selection for eligible decisions,
including projects with an existing on setting. Project off remains the default
and blocks automatic selection. Explicit historical reads still work while off.
Fresh evaluation, explicit Full or Super, and storage-only requests skip
automatic selection.

The helper returns historical candidates. Quorum checks material assumptions,
sources and reconsideration triggers against current evidence before relying on
a record. A locked exact-ID recheck verifies that the project is still enabled
and the record digest still matches. Withdrawal or a failed check requires a
fresh decision using independent current inputs. Global access remains explicit
and exact-ID based, with the existing admission boundary.
